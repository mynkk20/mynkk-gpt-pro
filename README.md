# mynkk GPT Pro - AI Agent Project

This project contains an autonomous ReAct AI Agent equipped with four tools (Calculator, Live Weather API, Local Knowledge Base, and DuckDuckGo Web Search) running on the Llama model.

## Project Contents:
- `agent_core.py`: Contains the tool definitions, ReAct template, and AgentExecutor configuration.
- `requirements.txt`: Python package dependencies.

## How to run locally:
1. Install dependencies: `pip install -r requirements.txt`
2. Set up your Groq API Key env variable.
3. Run your application script!
